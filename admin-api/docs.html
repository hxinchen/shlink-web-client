Quarks Click API

用一个 API Key 创建、管理和分析短链。业务接口只需要 X-Shlink-Api-Key，密钥管理接口和本页面继续由管理后台登录保护。

下载 OpenAPI JSON

认证

业务 API 根地址：https://admin.quarks.click/admin-api。每次请求添加请求头：

X-Shlink-Api-Key: YOUR_KEY
密钥只显示一次在后台“设置 → API 密钥”创建后立即保存完整值。禁用或删除密钥会立即阻止后续请求。

API Key 管理接口（/api-keys）使用管理后台 HTTP Basic Auth。

短链接口

GET/short-urls

分页查询短链。参数：page、itemsPerPage、searchTerm、tags。

curl -sS "https://admin.quarks.click/admin-api/short-urls?itemsPerPage=20" -H "X-Shlink-Api-Key: YOUR_KEY"
POST/short-urls

创建短链。longUrl 必填。

curl -X POST "https://admin.quarks.click/admin-api/short-urls" -H "X-Shlink-Api-Key: YOUR_KEY" -H "Content-Type: application/json" -d '{"longUrl":"https://example.com/docs","customSlug":"docs","tags":["public"]}'
GET/short-urls/{shortCode}

获取单条短链详情。

PATCH/short-urls/{shortCode}

更新目标地址、别名、标签、域名或有效期，只提交需要变更的字段。

DELETE/short-urls/{shortCode}

删除短链，成功返回 204 No Content。

创建字段

字段类型说明
longUrlstring目标 URL，必填。
customSlugstring自定义短码；不传则自动生成。
tagsstring[]用于筛选和分组的标签。
domainstring使用已配置的短链域名。
validSince / validUntilISO 8601生效和失效时间。
maxVisitsinteger达到次数后停止跳转。

访问分析

GET/short-urls/{shortCode}/visits

查询单条短链访问记录。支持 startDate、endDate、page、itemsPerPage。

GET/visits

查询所有短链的访问记录，包含时间、来源、国家/城市、浏览器和设备信息（取决于 Shlink 追踪配置）。

import requests
r = requests.get("https://admin.quarks.click/admin-api/visits", params={"startDate":"2026-01-01","itemsPerPage":50}, headers={"X-Shlink-Api-Key":"YOUR_KEY"})
r.raise_for_status()
print(r.json())
GET/domains/{domain}/visitsGET/tags/{tag}/visits

按域名或标签过滤访问记录。

API 密钥管理

以下接口需要管理后台 Basic Auth，完整密钥仅在创建响应中返回一次。

GET/api-keys

列出名称、状态、过期时间和权限。

POST/api-keys

创建密钥。支持 name、expirationDate、authorOnly、domainOnly、noOrphanVisits。

curl -u "ADMIN_USER:ADMIN_PASSWORD" -X POST "https://admin.quarks.click/admin-api/api-keys" -H "Content-Type: application/json" -d '{"name":"friend-alice","authorOnly":true}'
PATCH/api-keys/{name}

重命名：{"newName":"new-name"}；禁用：{"enabled":false}。

DELETE/api-keys/{name}

删除密钥，成功返回 204。

多语言示例

JavaScript / Node.js

const base = "https://admin.quarks.click/admin-api";
const headers = {"X-Shlink-Api-Key": process.env.SHORTLINK_KEY};
const response = await fetch(base + "/short-urls", {headers});
if (!response.ok) throw new Error(response.status + " " + await response.text());
console.log(await response.json());

Python

import os, requests
r = requests.post("https://admin.quarks.click/admin-api/short-urls",
    headers={"X-Shlink-Api-Key": os.environ["SHORTLINK_KEY"]},
    json={"longUrl":"https://example.com","tags":["campaign"]})
r.raise_for_status()
print(r.json())

PHP

$ch = curl_init("https://admin.quarks.click/admin-api/short-urls");
curl_setopt_array($ch, [CURLOPT_POST=>true, CURLOPT_RETURNTRANSFER=>true,
  CURLOPT_HTTPHEADER=>["X-Shlink-Api-Key: ".$_ENV["SHORTLINK_KEY"],"Content-Type: application/json"],
  CURLOPT_POSTFIELDS=>json_encode(["longUrl"=>"https://example.com"])]);
$result = json_decode(curl_exec($ch), true); curl_close($ch);

Go

req, _ := http.NewRequest("GET", "https://admin.quarks.click/admin-api/short-urls", nil)
req.Header.Set("X-Shlink-Api-Key", os.Getenv("SHORTLINK_KEY"))
res, err := http.DefaultClient.Do(req)
if err != nil { log.Fatal(err) }
defer res.Body.Close()

PowerShell

$headers = @{"X-Shlink-Api-Key"=$env:SHORTLINK_KEY}
$body = @{longUrl="https://example.com"} | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri "https://admin.quarks.click/admin-api/short-urls" -Headers $headers -Body $body -ContentType "application/json"

错误处理

状态码含义建议
400请求参数不合法检查 JSON、日期格式和 URL。
401缺少或无效 API Key确认请求头为 X-Shlink-Api-Key，并检查密钥状态。
404短码不存在确认 shortCode 和域名。
429触发限流使用指数退避重试。

机器可读定义：OpenAPI 3.1 JSON。
